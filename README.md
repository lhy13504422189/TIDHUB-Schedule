# TIDHUB Schedule · 潮汐课表

一个单文件、零依赖的课程表，附带可视化编辑器。

纯 HTML + CSS + 原生 JavaScript。无构建步骤，无 npm，无 CDN。保存后直接在浏览器打开即可使用。

## 功能

### 视图

- 两套布局：电脑端为网格表（大节成行、星期成列），手机端按天分组
- 根据 UA 与屏幕宽度自动选择布局，也可以手动切换
- 选择结果存入 `localStorage`，下次打开沿用

### 下节课卡片

- 顶部常驻「下节课」卡片，倒计时精确到秒
- 课程进行中自动切换为「正在上课」，倒计时目标改为下课时间
- 支持跨天查找：今天无剩余课程时跳至明天或下一个上课日
- 课程颜色与课表卡片保持一致
- 页面切到后台时暂停计时，回到前台立即刷新

### 课表高亮

两套互斥的高亮状态：

| 状态 | 触发条件 | 视觉表现 |
|---|---|---|
| 即将到来 `.is-soon` | 下一节尚未开始 | 边框描边 + 呼吸柔光 + 淡色进度填充 |
| 正在上课 `.is-now` | 当前时间在课程区间内 | 更强柔光 + 内发光 + 主题色整卡填充 |

进度条有两处：整张课表卡片本身，以及顶部的「下节课」卡片。两者与课程进度同步。

### 视觉

- 玻璃拟态：`backdrop-filter` + 半透明白背景 + 细边框 + 顶部渐变高光
- 背景使用多层径向渐变，为玻璃提供层次
- 每门课固定一种颜色，共 9 种可选
- 进度填充使用 `color-mix()` 与主题色混合，不需要单独配置透明度
- 系统启用 `prefers-reduced-motion` 时关闭所有动画

### 可视化编辑器（附带）

- 拖入课表 HTML，通过表单修改课程、教室、时间、颜色、星期
- 修改课程名时自动同步配色表
- 时间使用原生 `<input type="time">`，输出格式始终为 `HH:MM`
- 下载修改后的完整 HTML
- 全部在浏览器本地处理，不上传任何数据

## 快速开始

1. 下载 `index.html` 和 `editor.html`
2. 打开 `index.html` 查看默认课表
3. 打开 `editor.html`，把 `index.html` 拖入，修改为你自己的课表
4. 下载修改后的文件，覆盖原 `index.html`
5. 刷新页面

建议通过编辑器修改课表，不要直接改源码。原因见下方。

## 修改课表

提供两种方式。

### 方式一：可视化编辑器（推荐）

打开 `editor.html`，拖入 `index.html`，通过表单修改。

支持的修改项：

- 周次文字
- 星期的增删与排序
- 每个大节的起止时间
- 大节的增删与排序
- 每天的课程名与教室
- 每门课的颜色

编辑器能规避的手动修改常见错误：

| 常见错误 | 编辑器的处理 |
|---|---|
| 时间写成 `"8:20"` | 原生时间控件，输出始终补零 |
| 使用全角冒号 `"08：20"` | 输入层不可能产生该字符 |
| 空课写成 `'周四': null` | 课程名留空时自动删除对应 key |
| 新课程未添加颜色 | 自动分配一个未使用的颜色 |
| 修改课程名后未同步配色表 | 自动删除旧名、添加新名 |
| 增删大节时漏写逗号 | 序列化时自动处理 |

修改完成后点击「下载修改后的 HTML」，覆盖原文件。

### 方式二：直接修改源文件

打开 `index.html`，找到 `var SCHEDULE = { ... }` 直接修改。

```js
var SCHEDULE = {
  week: '第 10–11 周',
  days: ['周一', '周二', '周三', '周四', '周五'],
  slots: [
    {
      start: '08:20',
      end:   '09:55',
      courses: {
        '周一': { name: '现代史', loc: '9 楼东阶梯' },
        '周二': { name: '英语',   loc: '301' },
        '周三': { name: '现代史', loc: '9 楼东阶梯' },
        '周五': { name: '导论',   loc: '6 楼东阶梯' }
        // 周四没课，直接省略这个 key
      }
    },
    // 其他大节
  ]
};
```

这种方式有几个容易出错的地方：

| 规则 | 正确写法 | 错误写法 | 后果 |
|---|---|---|---|
| 时间补零 | `"08:20"` | `"8:20"` | 倒计时计算错误 |
| 英文冒号 | `"08:20"` | `"08：20"` | 被解析为 0 点 |
| 名字一致 | `days` 与 `courses` 都用 `'周一'` | 一处 `'周一'`、一处 `'星期一'` | 该课程不显示 |
| 空课省略 | 不写 `'周四'` 这一行 | 写 `'周四': null` | PC 视图出现空白占位卡 |
| 新增大节补逗号 | 上一块末尾加 `,` | 漏写 | JS 语法错误，页面白屏 |

如果坚持手改，需要修改的只有两处：

1. `SCHEDULE`：课程、时间、教室、周次
2. `COURSE_COLORS`：课程配色（可选）

`COURSE_COLORS` 的格式：

```js
var COURSE_COLORS = {
  '现代史':   'blue',
  '英语':     'purple',
  '导论':     'orange',
  '高数':     'indigo',
  '电信':     'pink',
  '韩语':     'green',
  '体育':     'teal',
  '人工智能': 'rose',
  '韩语听说': 'yellow'
};
```

可用颜色标识固定为 9 个：`pink` `rose` `orange` `yellow` `green` `teal` `blue` `indigo` `purple`。

未登记的课程会按名称哈希分配一个稳定颜色。可以正常显示，但颜色不一定是预期值，建议主动登记。

### 编辑器的实现说明

**数据提取方式：**

- 使用正则和括号匹配定位 `var SCHEDULE = { ... }` 和 `var COURSE_COLORS = { ... }`
- 使用 `new Function` 将对象字面量解析为普通对象（仅解析数据，不执行任何逻辑）
- 修改完成后序列化写回，保持源码格式

**不做的操作：**

- 不执行课表中的脚本
- 不上传文件
- 不改动 CSS、JavaScript 逻辑或 HTML 结构

**已知限制：**

- 导出时会丢失 `SCHEDULE` 和 `COURSE_COLORS` 两个块内的原有注释，因为序列化会重写这两个块
- 依赖 `var SCHEDULE = { ... }` 和 `var COURSE_COLORS = { ... }` 这两个声明形式。改为 `const`、使用 IIFE 包裹、或拆到外部文件都会导致提取失败

## 高级自定义

### 修改课程配色

在 `:root` 中找到以下变量：

```css
--pink-bg:   #FFE3EC;  --pink-tx:   #8F2047;
--blue-bg:   #DDEBFF;  --blue-tx:   #123F9E;
/* 其他颜色 */
```

- `-bg`：卡片底色
- `-tx`：文字颜色、进度填充色、高亮光晕主色

修改后课表卡片和顶部卡片会同步生效，无需改动 JavaScript。

### 调整进度条触发窗口

```js
var SOON_WINDOW_MS = 60 * 60 * 1000;   // 默认 60 分钟
```

「即将到来」状态开始显示进度的距离开课时间。增大该值会让进度条更早开始推进。

### 调整动画参数

| 效果 | 位置 |
|---|---|
| 描边光带旋转周期 | `@keyframes cardStrokeSpin` 中的 `3.6s` |
| 即将到来状态呼吸周期 | `@keyframes cardSoonBreath` 中的 `3.4s` |
| 正在上课状态呼吸周期 | `@keyframes cardNowBreath` 中的 `2.4s` |
| 光晕强度 | 各 `box-shadow` 中 `color-mix(...)` 的百分比参数 |

### 移除描边光带

删除 `.c-card.is-soon::after` 整块 CSS。`.is-soon` 和 `.is-now` 会变成纯呼吸柔光效果。

### 修改标题文字

```html
<h1>课程表 <span class="week-badge" id="week-badge">第 10–11 周</span></h1>
```

修改 `<h1>` 中的文本即可。

## 浏览器兼容性

### 完整效果支持版本

| 浏览器 | 版本 |
|---|---|
| Chrome / Edge | 111+ |
| Safari | 16.4+ |
| Firefox | 128+ |

### 降级行为

| 特性 | 不支持时的表现 |
|---|---|
| `color-mix()` | 进度填充与光晕退化为透明或中性色；描边、呼吸动画、倒计时仍正常工作 |
| `@property --angle` | 描边光带停在起始位置，不再旋转 |
| `backdrop-filter` | 玻璃卡片退化为纯白半透明背景，功能不受影响 |

以上降级均不会影响核心功能的运行。

## 设计说明

### 整卡进度条

常见做法是在卡片底部增加一条细进度条，存在几个问题：

- 3px 高度在视觉上难以辨识
- 两端难以做出圆角
- 与卡片的整体视觉风格不协调

将整张卡片作为进度容器后：

- 进度信息一目了然
- 填充色为主题色与透明度的混合，不会遮挡文字
- 卡片圆角天然裁切填充层
- 顶部卡片与课表卡片同步填充，可直接看出课程正在推进

### 高亮动画的实现思路

早期版本尝试过斜向流动光带，效果不理想：

- 看起来接近演示文稿动画
- 斜向光带与卡片圆角冲突
- 高频扫过容易造成视觉疲劳

当前实现使用三层组合：

1. `conic-gradient` 描边光带：同色光点沿边框旋转，周期 3.6 秒
2. 主题色柔光：`color-mix()` 混合，过渡自然
3. 缓慢呼吸：周期 3.4 秒或 2.4 秒，避免闪烁

### 为什么只使用原生 JavaScript

- 无构建步骤，保存即可使用
- 单文件，便于分发和静态托管
- 数据驱动，所有可配置项集中在两个对象中
- 定时器每秒触发一次，性能开销可忽略，没有框架层面的隐含行为

### 定时器策略

- `setInterval(updateNextCard, 1000)` 每秒刷新
- 页面隐藏时 `clearInterval` 暂停
- 回到前台时立即执行一次并重启定时器
- 内容未变化时跳过 DOM 写入（比较上次状态 key）
- 状态切换时临时禁用 CSS `transition`，防止进度条出现回退动画

## FAQ

**修改了课表但页面没有变化？**

如果使用编辑器，确认是否点击了「下载」并覆盖了原文件。如果手改源码，检查：

1. 时间格式是否为 `"HH:MM"`，两位、补零、英文冒号
2. `days` 和 `courses` 中的名字是否完全一致
3. 浏览器控制台是否有报错

**添加周末后 PC 视图列数不对？**

PC 网格列数写死在 CSS 中。搜索 `repeat(5, minmax(0, 1fr))` 和 `grid-template-columns: 112px repeat(5, minmax(0, 1fr))`，将两处 `5` 改为新的天数。手机视图不受影响。使用编辑器添加星期时不会自动修改这两处。

**倒计时停止更新？**

通常是某一大节的时间格式有误。用编辑器检查，或核对对应大节的 `start` / `end` 是否符合 `"HH:MM"`。

**高亮效果不显示？**

打开控制台检查 `--c-tx` 等 CSS 变量是否正常。较旧浏览器可能不支持 `color-mix()`，此时进度填充会退化为透明，但描边与柔光仍会显示。

**编辑器无法提取数据？**

编辑器依赖 `var SCHEDULE = { ... }` 和 `var COURSE_COLORS = { ... }` 这两个声明形式。改为 `const`、使用 IIFE 包裹、或拆到外部文件都会导致提取失败。恢复为默认写法即可。

**编辑器导出的文件丢失了注释？**

是。序列化会重写 `SCHEDULE` 和 `COURSE_COLORS` 两个块，原有注释会丢失。功能不受影响。

**能否支持节假日标记、单双周、多份课表？**

当前版本未内置。`SCHEDULE` 是数据驱动的，扩展 `weeks` 字段可以实现单双周；节假日可以给 slot 增加 `tag` 字段并在渲染时判断日期。欢迎提交 PR。
